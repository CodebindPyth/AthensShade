# Δεδομένα AthensShade

Το `processed/athens.json` είναι το δημόσιο στιγμιότυπο που χρησιμοποιεί ο backend. Τα GIS επίπεδα έχουν συντεταγμένες WGS84 και μπορούν να διαβαστούν χωρίς σύνδεση στις πηγές. Τα δεδομένα που εξάγονται από δημόσιες πηγές αναφέρονται στο `sources`.

| Επίπεδο | Πηγή και επεξεργασία |
| --- | --- |
| Θερμοκρασία επιφάνειας | Μέση ημερήσια θερμοκρασία επιφάνειας για Ιούνιο–Αύγουστο 2016–2020. Ο δείκτης ανά κελί 175 μ. είναι ο μέσος των θερμοκρασιών `avgLST`, σταθμισμένος κατά την επιφάνεια επικάλυψης. Κελιά με κάλυψη κάτω από 70% δεν δημοσιεύονται. Δεδομένα EXTREMA Global Services και ARTi Analytics BV, δημοσίευση Δήμου Αθηναίων. [Κατάλογος και άδεια CC BY 3.0 GR](https://opendata.cityofathens.gr/dataset/gis-athens-057aff6a-f337-11ee-b64b-0242ac120004) |
| Δενδροκάλυψη | Ποσοστό οριζόντιας κάλυψης από κόμη το 2018. Μέσο από έγκυρα pixels του Copernicus Tree Cover Density 10 μ. για κάθε κελί. Προσαρμοσμένα δεδομένα Copernicus Land Monitoring Service. [Κατάλογος](https://doi.org/10.2909/486f77da-d605-423e-93a9-680760ab6791) |
| Καταγραφές φυτεύσεων | Δημόσια σημεία που υπήρχαν στον χάρτη AthensTrees στις 21 Νοεμβρίου 2026, ομαδοποιημένα ανά κελί 175 μ. Κάθε σημείο αντιστοιχεί σε εγγραφή του χάρτη και μπορεί να αφορά ένα ή περισσότερα δέντρα. Η θέση του δείκτη δείχνει το κέντρο των εγγραφών του κελιού. [Δημοτικός χάρτης](https://athenstrees.cityofathens.gr/) |
| Κοινότητες και σχολεία | Δημοτικά δεδομένα GIS. Οι περιγραφές των σχολείων ανακτήθηκαν από το αυθεντικό συνοδευτικό DBF UTF-8. [Κοινότητες](https://opendata.cityofathens.gr/dataset/gis-athens-26fc7f34-6439-11ee-88f1-0242ac120004), [δείκτες σχολείων](https://opendata.cityofathens.gr/dataset/gis-athens-3bbfb156-7722-11ee-bdf0-0242ac120004), [άδεια CC BY 3.0 GR](https://creativecommons.org/licenses/by/3.0/gr/) |
| Πληθυσμιακή πυκνότητα | Εκτιμώμενοι μόνιμοι κάτοικοι ανά km² από το πλέγμα 100 μ. JRC–Eurostat. Η αρχική απογραφή 2021 σε κελιά 1 km² κατανέμεται με βάση εκτιμήσεις του όγκου των κτιρίων κατοικίας. Ο δείκτης του σημείου σταθμίζει τα κελιά ανά επιφάνεια επικάλυψης σε ακτίνα 100 μ. [JRC–Eurostat, αναθεώρηση Ιουλίου 2026](https://data.jrc.ec.europa.eu/dataset/98336641-fd1c-4992-8c7b-c470dd5eb81e) |

Ο έλεγχος κάθε υποψήφιας θέσης χρησιμοποιεί ακτίνα 100 μ. γύρω από δημοσιευμένο σημείο αναφοράς της περιοχής. Η θερμοκρασία και η δενδροκάλυψη είναι μέσοι της ακτίνας και μπορεί να διαφέρουν από το κελί του χάρτη. Οι καταγραφές φυτεύσεων δείχνουν τεκμηριωμένες εργασίες, ενώ η σημερινή επιβίωση των δέντρων, η σκιά από υποδομές και ο διαθέσιμος χώρος χρειάζονται επιτόπιο έλεγχο. [Δημοτική απόφαση 717/2025](https://www.cityofathens.gr/wp-content/uploads/2025/11/717-25.pdf)

Οι ποσότητες και οι δαπάνες είναι παραδοχές σχεδιασμού προ ΦΠΑ. Για τη φύτευση χρησιμοποιήθηκε η τιμή αναφοράς 220 € ανά δέντρο κατηγορίας Δ9 για προμήθεια. Για τα ιστία χρησιμοποιήθηκαν 49,43 €/m² από δημοπράτηση σχολείων. Τα σενάρια προσθέτουν ενδεικτικά συνοδά έργα. Οι ποσότητες, η προσαρμογή των τιμών και η καταλληλότητα των χώρων χρειάζονται έλεγχο. [Τιμολόγιο φυτεύσεων](https://www.cityofathens.gr/wp-content/uploads/2024/01/timologio-dimopratisis-erga-odopoiias-kai-diktyon-omvrion-apocheteysis-periochi-elaiona-2024.pdf#page=110), [τιμολόγιο σκίασης](https://www.cityofathens.gr/wp-content/uploads/2024/06/timologio-dimopratisis-ergo-syntiriseis-scholikon-ktirion-dimoy-athinaion-7i-dimotiki-koinotita.pdf#page=74)

Για δέντρα, η προβολή ώριμης κόμης είναι ενδεικτική και βασίζεται σε διάμετρο 3–5 μ. ανά δέντρο. Για σκίαστρα, χρησιμοποιείται η προβλεπόμενη οριζόντια επιφάνεια των ιστίων. Η πραγματική έκταση του εδάφους που σκιάζεται εξαρτάται από τον ήλιο, τη χωροθέτηση και τις επικαλύψεις. Η μεταβολή θερμοκρασίας θα απαιτούσε βαθμονομημένο μικροκλιματικό μοντέλο και μελέτη ανά θέση.

Τρία σενάρια εκτατικού φυτεμένου δώματος χρησιμοποιούν τεκμηριωμένες θέσεις δημόσιων σχολείων. Το εμβαδό επέμβασης είναι παραδοχή του σεναρίου. Χρησιμοποιούνται ως σημεία αναφοράς 24,20 €/m² για αποστράγγιση, 2,10 €/m² για φίλτρο και 280 €/m³ για υπόστρωμα. Τα κόστη περιλαμβάνουν πρόσθετη ενδεικτική πρόβλεψη εργασιών και μελέτης. Ο μηχανικός επιβεβαιώνει τη διαθέσιμη επιφάνεια, τη δυνατότητα ασφαλούς πρόσβασης, τη στατική επάρκεια, τη στεγάνωση, την απορροή και τη συντήρηση. Η έκταση του φυτεμένου δώματος εμφανίζεται χωριστά από την προβολή σκίασης πεζών. [Τιμολόγιο Περιφέρειας Πελοποννήσου, άρθρα Η.62–Η.64](https://www.ppel.gov.gr/wp-content/uploads/2022/07/5.-%CE%A4%CE%99%CE%9C%CE%9F%CE%9B%CE%9F%CE%93%CE%99%CE%9F-%CE%91%CE%A3%CE%A4%CE%95%CE%A1%CE%9F%CE%A3%CE%9A%CE%9F%CE%A0%CE%95%CE%99%CE%9F.pdf)

## Ανανέωση

Από τη ρίζα του αποθετηρίου, με Python 3.12 ή νεότερη και πρόσβαση στα δημόσια endpoints για την πρώτη λήψη:

```bash
python -m pip install -r scripts/requirements-data.txt
python scripts/build_dataset.py --snapshot-date YYYY-MM-DD
```

Το `--snapshot-date` είναι η ημερομηνία ανάκτησης του `athenstrees-map.json`. Χρησιμοποίησε νέο κατάλογο `--raw` για να ανανεώσεις τις λήψεις χωρίς να αντικαταστήσεις ένα προηγούμενο στιγμιότυπο. Τα αρχεία του `data/raw` είναι τοπική προσωρινή μνήμη. Το `--output` επιτρέπει τη δοκιμαστική δημιουργία σε χωριστή διαδρομή.
